# सम्राट टेलर्स — वेबसाइट ऑनलाइन कैसे डालें

यह पूरी वेबसाइट तैयार है. अब इसे इंटरनेट पर डालना है, जिसके लिए **होस्टिंग** चाहिए. होस्टिंग वो जगह है जहाँ वेबसाइट रहती है. यह आपके नाम पर ही खरीदी जाती है.

## 1. होस्टिंग और डोमेन लें
- कोई भी **PHP होस्टिंग** चलेगी, जैसे Hostinger, GoDaddy या BigRock. "Single / Premium Web Hosting" प्लान काफ़ी है.
- साथ में डोमेन नाम लें, जैसे `samrattailors.in`.
- PHP का version **8.0 या उससे नया** होना चाहिए. नई होस्टिंग में यह पहले से होता है.

## 2. फ़ाइलें अपलोड करें
1. होस्टिंग पैनल में **File Manager** खोलें, फिर `public_html` फ़ोल्डर में जाएँ.
2. `samrat-tailors.zip` अपलोड करें. फिर उस पर right-click करके **Extract** करें.
3. `samrat-tailors` फ़ोल्डर के **अंदर की सारी फ़ाइलें** सीधे `public_html` में होनी चाहिए. यानी `public_html/index.php` दिखना चाहिए.

बस. कोई डेटाबेस बनाने या कोड बदलने की ज़रूरत नहीं. डेटा अपने-आप `data/` फ़ोल्डर में सेव होगा.

## 3. पहली बार खोलें
1. अपनी वेबसाइट खोलें (जैसे `https://samrattailors.in`).
2. **"पहली बार: मास्टर अकाउंट बनाएँ"** दिखेगा. मास्टर जी का नाम, यूज़रनेम (जैसे `master`) और पासवर्ड डालें.
3. **कारीगर** टैब में हर कारीगर जोड़ें: नाम, यूज़रनेम (जैसे `shahjade`) और पासवर्ड. हर कारीगर को उसका यूज़रनेम और पासवर्ड बता दें.
4. **सेटिंग** में कपड़ों का सामान्य रेट डालें. किसी कारीगर का रेट अलग है तो **कारीगर** में उसका नाम खोलकर उसका रेट डालें.

## 4. फ़ोन में ऐप जैसा लगाएँ
हर फ़ोन में Chrome से वेबसाइट खोलें, फिर ⋮ मेनू → **Add to Home screen**. लॉगिन 30 दिन तक बना रहता है.

## रोज़ का काम
- **मास्टर जी:** "काम दें" में कॉपी नंबर (601), कपड़ा, पीस और कारीगर चुनें, फिर **काम दें**. रेट अपने-आप भर जाता है.
- **कारीगर:** "मेरे काम" में अपना काम दिखेगा. कपड़ा तैयार होते ही **✓ पूरा हुआ** दबाएँ.
- **मास्टर जी:** "सभी काम" में दिखेगा क्या बाकी है और क्या पूरा. "हिसाब" में हर कारीगर का बाकी भुगतान दिखेगा. पैसे देने के बाद **भुगतान दर्ज करें** दबाएँ.

## बैकअप
**सेटिंग → पूरा रिकॉर्ड डाउनलोड करें** से Excel फ़ाइल मिलती है. महीने में एक बार रख लें. पूरा बैकअप चाहिए तो File Manager से `data/samrat.sqlite` फ़ाइल डाउनलोड कर लें.

## कभी ज़रूरत पड़े
- **मास्टर पासवर्ड भूल गए:** File Manager में `config.php` खोलें. `reset_master_password` में नया पासवर्ड (कम से कम 6 अक्षर) लिखें और सेव करें. उस पासवर्ड से लॉगिन करें, फिर वहाँ से उसे हटाकर फिर से `''` (खाली) कर दें. डेटा सुरक्षित रहता है.
- **कारीगर पासवर्ड भूल गया:** मास्टर जी "कारीगर" में उसका नाम खोलकर नया पासवर्ड सेट कर दें.
- **होस्टिंग MySQL ही देती है:** `config.php` खोलकर `db_driver` को `'mysql'` करें और MySQL की जानकारी भरें.
- **वेबसाइट https पर खोलें:** होस्टिंग पैनल में मुफ़्त SSL चालू कर दें. इससे पासवर्ड सुरक्षित रहते हैं.
